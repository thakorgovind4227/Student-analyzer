# Student Analyzer

## Project Overview

Student Analyzer is a console-based application developed using Python.

It helps manage student information, calculate academic performance, and analyze student results.

Users can add multiple students, calculate marks and percentages, search student records, update information, and delete records.

## Project Objectives

- Manage student personal and academic information.
- Calculate total marks and percentages.
- Determine student results based on marks.
- Analyze overall student performance.
- Identify students with the highest and lowest percentages.
- Count passed and failed students.

## Features

### 1. Student Management
- Add student details.
- Add multiple students in one execution.
- Store student personal and academic information.

### 2. Marks Calculation
- Calculate total marks.
- Calculate percentage.
- Determine Pass or Fail status.
- Assign performance grades.

### 3. Performance Analysis
- Calculate average percentage.
- Find the highest percentage.
- Find the lowest percentage.
- Count passed and failed students.

### 4. Student Operations
- Search student records by name.
- Update student details and marks.
- Delete student records.

## Grading Criteria

| Percentage | Result |
|---|---|
| 75% and above | Excellent |
| 60% – below 75% | Very Good |
| 50% – below 60% | Good |
| Below 50% | Pass |
| Any subject below 35 marks | Fail |

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Make sure Python is installed.
4. Open the terminal.
5. Run the Python file:

```bash
python main.py
```
